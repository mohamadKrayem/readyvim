# Neovim

Part of [my dotfiles](../README.md) — see the root README for install and layout.

## Notable plugins

- **telescope.nvim** — fuzzy finding files, buffers, grep
- **nvim-lspconfig** + **mason.nvim** — language servers, installed on demand
- **nvim-treesitter** — syntax, indentation, and the `[[` / `]]` container motions
- **multicursor.nvim** — multiple cursors
- **nvim-dap** — debugging
- **none-ls.nvim** — formatting and diagnostics from non-LSP tools
- **gitsigns.nvim** + **lazygit.nvim** — in-buffer hunks and the full git UI
- **yazi.nvim** — yazi as the file manager

See [SHORTCUTS.md](SHORTCUTS.md) for every keymap.
